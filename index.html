      Research

      Budget-Coupled Robust Belief Propagation for Visual Hallucination Detection

      Paper in progress. Code is public; there are no results yet.

      When a vision-language model says "there is a dog in this image", how much should we believe it? I treat the claim and the visual evidence for it as a tree-shaped graphical model and run exact belief propagation. Then I let an adversary corrupt the evidence within a budget, and compute the lowest and highest belief it can force. A claim is only kept if even the lowest value clears the bar.

      An illustration of the method on a made-up seven-node tree, not results. Saffron dots are messages moving toward the claim. Red rings mark the evidence the adversary corrupts to pull the belief down.

      Where it is now

      • The inference code is written and tested: exact belief propagation, a brute-force check, and the budget-coupled solver.
      • Current question: do conformal hallucination filters calibrated on clean images keep their guarantee when the visual evidence shifts, and does a shift-calibrated evidence radius restore it?
      • Next: evaluation on human-labelled claims.
